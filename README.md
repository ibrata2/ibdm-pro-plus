# IBDM Pro

مدير تحميل لـ Windows — **برمجة و تطوير ابراهيم الخزرجي**

## التحميل
آخر إصدار: **[IBDM-Pro-Setup.exe](https://github.com/ibrata2/ibdm-pro-plus/releases/latest/download/IBDM-Pro-Setup.exe)**
(إذا طلع تحذير Windows: More info ← Run anyway)

## المميزات
- **التقاط التحميلات من أي موقع**: إضافة للمتصفح (Chrome / Edge) توقف تحميل المتصفح وترسل الملف للبرنامج.
- **نافذة «معلومات الملف» قبل التحميل**: الاسم، الحجم، النوع، هل يدعم التحميل المجزأ، والمساحة المتوفرة — وتختار وين ينحفظ.
- **تحميل سريع بعدة اتصالات** (حتى 32 اتصال لكل ملف) مع إيقاف واستئناف حتى بعد إطفاء الجهاز.
- **تحميل الفيديو**: يعرض كل الجودات المتوفرة مع حجم كل جودة (4K، 1080p، 720p…) — ويوتيوب، انستغرام، فيسبوك، تيك توك وآلاف المواقع.
- **صوت فقط**: MP3 أو M4A بالجودة الأصلية.
- **مجلد خاص للبرنامج** `التنزيلات\IBDM Pro` وبداخله **مجلد لكل نوع**: فيديو، صوتيات، مضغوطات، برامج، مستندات، صور، تورنت، أخرى — وتقدر تغيّر الأنواع والمجلدات.
- **تتحكم بالملفات التي يلتقطها**: قائمة الامتدادات، الحد الأدنى للحجم، ومواقع يتركها للمتصفح.
- زر «تحميل هذا الفيديو» يظهر فوق أي فيديو بالصفحة، وقائمة زر يمين «تحميل بواسطة IBDM Pro».
- حد أقصى للسرعة، عدد التحميلات بنفس الوقت، تشغيل مع Windows، إشعار عند الاكتمال.
- **قوائم انتظار متعددة**: أنشئ قوائم وابدأ أو أوقف كل قائمة، واختر القائمة عند إضافة تحميل أو انقله إليها لاحقاً.
- قوائم منسدلة أعلى النافذة للتحكم بالتحميلات والعرض والإعدادات، مع زر تحميل جديد.

## البناء
كل دفع (push) لـ `main` يشغّل اختبارات المحرك الحقيقية ثم يبني البرنامج والمثبّت وينشر إصدار جديد تلقائياً.
- `src/IbdmPro.Core` — محرك التحميل (يُختبر على Linux بـ `tests/run.sh`)
- `src/IbdmPro.App` — واجهة Windows (WPF، عربي من اليمين لليسار)
- `extension` — إضافة المتصفح
- `installer` — مثبّت Inno Setup بالعربي

يستخدم [yt-dlp](https://github.com/yt-dlp/yt-dlp) و [FFmpeg](https://ffmpeg.org).
