# IBDM Pro Plus

نسخة مستقلة معدّلة من IBDM Pro لإدارة التحميلات.

## التعديلات
- قوائم انتظار متعددة مع إمكانية إنشاء القوائم وبدئها وإيقافها.
- اختيار القائمة عند إضافة رابط، ونقل التحميلات الموجودة بين القوائم.
- قوائم منسدلة للتحكم بالتحميلات والعرض والإعدادات.
- زر تحميل جديد، مع البحث عن الفيديوهات في صفحات الروابط.
